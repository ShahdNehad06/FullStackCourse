# Account Portal

A small React + TypeScript project with register, login, profile and logout.
The accounts are saved in the browser (localStorage).

## How to run

```
npm install
npm run dev
```

## Folders

- `src/context` - AuthContext (the user, register, login, logout)
- `src/components` - Navbar, LoginForm, RegisterForm, Profile, Input
- `src/utils/validators.ts` - the form validation functions
